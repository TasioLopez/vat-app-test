# ValentineZ Assist Tool (VAT)  
## Klantoverzicht — verbonden 2e-spoor platform

**Voor:** ValentineZ  
**Datum:** 24 november 2026  
**Voorstel:** €49 per gebruiker / maand + AI-gebruik tegen kostprijs

---

## 1. Samenvatting (eerst dit)

VAT is één verbonden platform voor jullie 2e-spoorwerk: dossiers, Trajectplan, VGR, CV, intake, AI-ondersteuning, documentarchief en reserveringen (ruimte/parkeren).

| | |
|--|--|
| **In plaats van** | Apart CRM + Word + generieke AI + mappen + mail voor boekingen |
| **Krijgen jullie** | Één systeem waarin data één keer wordt vastgelegd en doorstroomt |
| **Al bewezen** | sep–nov 2026: **325 Trajectplannen**, **164 CV’s**, **218 werkgevers**, ~**30** gebruikers |
| **Tijd** | TP: **~3 uur → ~30 minuten** · CV: **~2 uur → ~10 minuten** |
| **Prijs** | **€49 / gebruiker / maand** + AI alleen voor wat jullie verbruiken (~€500/mnd nu) |
| **Bij 30 gebruikers** | Platform **≈ €17.640/jaar** + AI **≈ €6.000/jaar** ≈ **€23.600/jaar** |

**Kern:** Voor ongeveer dezelfde softwarekosten als alleen een mid-tier CRM krijgen jullie het document-besturingssysteem dat die CRM’s niet bieden — en winnen adviseurs honderden uren om meer cases te draaien.

## 5. Vergelijking in één oogopslag

### A. Functionaliteit — VAT vs standaard-CRM (bijv. Tribe)

| Behoefte | VAT | Standaard-CRM (ook top-tier) |
|----------|:---:|:----------------------------:|
| Trajectplan + AI vanuit dossier | ✓ | ✗ |
| VGR gekoppeld aan TP | ✓ | ✗ |
| CV-bouwer + deellink | ✓ | ✗ |
| Intake-AI / documentextractie | ✓ | ✗ |
| Gespreksverslag uit opname | ✓ | ✗ |
| Reserveren ruimte/parkeren | ✓ | ✗ |
| Generieke CRM / salespipeline | Roadmap | ✓ |

**Voor projecten/tickets in een los CRM is Advanced (~€69/gebruiker/mnd lijst) de passende Tribe-tier — en jullie hebben alsnog VAT (of handmatig Word + AI) nodig voor documenten.**

## 8. Waarom doorgaan

1. **Werkt al** — honderden TP’s en CV’s in ~12 weken.  
2. **Voor jullie vak** — 2e-spoordocumenten, geen generieke sales-CRM.  
3. **Eenvoudig model** — €49/gebruiker + AI die jullie echt gebruiken.  
4. **Eerlijk t.o.v. alternatieven** — vergelijkbare softwarekosten, wél de workload die CRM niet doet.  
5. **Één roadmap** — dossiers → documenten → operatie → CRM.

---

## 9. Voorstel volgende stap

1. Bevestig **30 seats** à **€49 / gebruiker / maand**.  
2. Houd **AI pass-through** (transparant maandelijks verbruik).  
3. Stem CRM-in-VAT timing af (**jan vs jun 2027**).  
4. Plan adoptie zodat meer gebruikers dezelfde tijdwinst pakken.
